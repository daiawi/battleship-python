# Battleship-Python
During my undergrad, I took several attempts at coding my own version of the classic game battleship. Each time, I would get lost in the implementation and eventually give up. 

In the summer between my Master's and my PHD, I've decided to come back and finally finish this project. This time, I'm starting from a fresh slate with a better understanding of the fundamentals. This project is 90% for fun, to kill some time while waiting for school to start. 

Hopefully it's not the worst implementation you've seen!
